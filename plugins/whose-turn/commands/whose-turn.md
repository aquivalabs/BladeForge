description: Open the Whose Turn monitor window
allowed-tools: Bash(node ${CLAUDE_PLUGIN_ROOT}/bin/app.mjs open:*)
---
Run `node ${CLAUDE_PLUGIN_ROOT}/bin/app.mjs open $ARGUMENTS` to open the Whose Turn window as its own app window, then say in one line that it is open. With the argument `--browser` it opens in a browser tab instead.
