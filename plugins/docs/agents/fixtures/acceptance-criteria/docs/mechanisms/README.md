# Mechanisms

## Boundary

This root holds documentation for mechanisms: code behavior with more than one moving part. It does
not hold architecture decisions and does not hold frozen specs.

## Shape

One short markdown file per mechanism, named for the mechanism it documents.

## Update trigger

A mechanism doc is revisited whenever the mechanism's own behavior changes.

## Exclusions

Nothing under this root documents a one-time decision; that belongs to the ADR layer.

## Acceptance criteria

Every document under this root names an owner and a last-reviewed date.
