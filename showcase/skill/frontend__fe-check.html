fires when

Typecheck and run (targeted) unit tests for a frontend repo, returning a terse one-block summary. Use after editing TypeScript/React to quickly confirm types are clean and the relevant tests pass — instead of running tsc and vitest separately and reading full output. Do NOT use for reviewing a diff, nor for any Apex or Salesforce-org check — this runs the frontend tsc + vitest and nothing else.

best for

Any TypeScript/React repo with tsc + vitest configured, pulled in right after editing code to confirm types and relevant tests still pass before moving on.
