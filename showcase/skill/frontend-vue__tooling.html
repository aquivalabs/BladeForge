frontend-vue:tooling v0.1.1

The Vue project toolchain from templates — ESLint flat config with eslint-plugin-vue and typescript-eslint carrying the house rules, Prettier, Stylelint with the BEM pattern, vue-tsc — and the one check command that gates a merge through the pre-push hook and CI.

fires when

Use when setting up, changing or running the toolchain of a Vue project — ESLint with eslint-plugin-vue and typescript-eslint, Prettier, Stylelint with the BEM selector pattern, vue-tsc type checking, the one `npm run check` that runs all of them with the tests, the pre-push hook or CI job that gates a merge on it, or when lint, format and type errors conflict or a rule needs turning on or off. NOT for writing the tests themselves (frontend-vue:testing) nor for the style rules' content (frontend-vue:bem-styles, frontend-js:conventions).

best for

Vue 3 projects that want lint, format, style lint and type checks set up once the house way and run before every merge.
