frontend-vue:nuxt-conventions v0.1.1

Where files live and how data flows in a Nuxt 3 or 4 project — the convention directories, auto-imports, useFetch and useAsyncData with keys, server routes with validated input, runtime config over process.env, rendering chosen per route.

see it

fires when

Use when the project is Nuxt 3 or 4 — creating pages, layouts, server routes or middleware, fetching data with useFetch or useAsyncData, relying on auto-imports, choosing rendering (SSR, SSG, SPA, hybrid routes), configuring modules in nuxt.config, handling runtime config and environment, or reviewing a Nuxt file placement. NOT for a plain Vite + Vue Router app (frontend-vue:component-architecture) and NOT for the inside of a component (frontend-vue:sfc-conventions).

best for

Nuxt projects that want pages, server routes and data fetching written the way Nuxt expects, with the other frontend-vue skills applying unchanged inside.
