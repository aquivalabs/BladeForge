frontend-vue:sfc-conventions v0.1.1

The house shape of a Vue single-file component — script setup with TypeScript, Composition API only, typed props and emits, defineModel, declarative templates, derived state over stored state, watchers only for effects.

see it

fires when

Use when writing, editing or reviewing a Vue single-file component — the <script setup lang=\"ts\"> block, props and emits and their types, defineModel, slots, template syntax, refs and computeds, watchers, lifecycle, the order of blocks in the .vue file, component and file naming. Also for converting an Options API or a JavaScript component to Composition API with TypeScript. NOT for where a component lives (frontend-vue:component-architecture), its styles (frontend-vue:bem-styles), a Pinia store (frontend-vue:state-pinia), or a reusable composable (frontend-vue:composables-vueuse).

best for

Vue 3 projects that want every component written and reviewed the same way, including conversions from the Options API or plain JavaScript.
