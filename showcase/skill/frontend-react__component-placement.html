Entry point BEFORE creating ANY React component, in any React codebase — search for an existing one first, decide placement (primitive / feature / layout / page-local), then route to the matching per-type skill. Any team building React UI that wants to stop duplicate components and enforce a consistent placement convention before scaffolding.
