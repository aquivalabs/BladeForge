fires when

Run anonymous Apex or a SOQL query against a Salesforce org and get a terse pass/fail result. Use whenever you need to execute anonymous Apex, reproduce an org-side error, or run a quick SOQL check against a dev/scratch org — instead of hand-rolling `sf org display` + curl to the Tooling API. Do NOT use to deploy or retrieve metadata (use `sf-deploy-test`), to describe an object schema or field names (use `dx_mcp`/`as_mcp`), or to build UI — this only runs anon Apex and SOQL.

best for

Anyone doing Salesforce org-side dev work who needs a quick anonymous-Apex/SOQL check without hand-rolling the sf CLI token + curl recipe.
