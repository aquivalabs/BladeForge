fires when

Route every user-facing UI string through the project's localization system instead of hardcoding it. Activate whenever writing or editing display text a user will see — labels, buttons, messages, errors, toasts, placeholders, empty states, flavor copy — in any project and any stack. Do NOT use for text a user never reads: log lines, internal error codes, test fixtures, code identifiers, enum keys, slugs, or proper-noun/canonical identifiers (those stay as plain data).

best for

Any project with user-facing UI text — teams that want new labels/messages/toasts to land in the existing i18n catalog/namespace rather than as scattered string literals.
