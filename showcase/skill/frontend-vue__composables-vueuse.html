see it

fires when

Use when a Vue component needs behaviour that is not display — reading or writing local storage, the colour scheme or a media query, the clock, window size, an event source or websocket, a debounce or throttle, the clipboard, focus, keyboard shortcuts, intersection, drag position, fetch with abort — or when about to write a use* composable, review one, or decide whether a piece of logic belongs in a composable, a store or a component. VueUse is checked first. NOT for app-wide state (frontend-vue:state-pinia) and NOT for React hooks (frontend-react:hooks-registry).

best for

Vue 3 projects that want behaviour (storage, media queries, time, events, streams, debounce, focus, drag) taken from VueUse instead of rewritten, and their own composables written consistently.
