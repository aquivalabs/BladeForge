Before hand-rolling a shared UI primitive (button, input, dialog, tooltip, etc.), search the project's existing primitive library and reuse or extend it instead of creating a duplicate.

fires when

Before creating ANY shared/reusable UI primitive in a React codebase (button, input, checkbox, radio, switch, select, textarea, dialog, tooltip, dropdown, badge, card, separator…), search the project's primitive library first to avoid duplicates — reuse or extend what exists; build new only when truly absent. Framework-agnostic (no specific UI or styling library assumed). Activate whenever about to add or hand-roll a reusable field/control/primitive.

best for

React codebases with (or growing) a shared primitives folder, pulled in whenever someone is about to add a new reusable field/control/overlay component.
