Motion in Vue by the cheapest tool that works — CSS transitions, Transition and TransitionGroup, the View Transitions API, a motion library last — animating transform and opacity, with durations from tokens and a reduced-motion fallback every time.

see it

fires when

Use when adding or reviewing motion in a Vue app — a sheet or dialog that fades in, a list whose rows enter and leave, a highlight that pulses on new items, a route transition, a drawer that slides, a counter that animates, a skeleton shimmer — or when choosing between CSS transitions, Vue Transition and TransitionGroup, the View Transitions API, and a motion library. Also when motion must respect prefers-reduced-motion. NOT for the dot-animal or canvas drawing of a specific app, and NOT for React (Motion for React is its own choice).

best for

Vue projects adding sheets, list changes, highlights and route transitions that should feel quick and respect user settings.
