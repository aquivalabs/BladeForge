meta:skill-eval v2.7.0

Faithful trigger scoring for an existing skill — the bundled score-description.py installs it as a real .claude/skills/ in a sandbox, runs real `claude -p` probes, scores 0-10 with current-vs-baseline no-regression, and says how to diagnose a miss rather than patch it. The canonical measurer; replaces skill-creator's false-negative-prone run_eval.

fires when

Use when you need to know whether a skill's `description` actually makes Claude reach for it — scoring an existing skill's trigger accuracy before shipping it, after editing its description, or when someone reports that a skill \"never triggers\" and you need to find out why. Also use to read a score you already have: what a miss means, and what a should-not-trigger query that fired means. Do NOT use to REWRITE a skill's description or body (use `meta:update-skill` — measuring is this skill's job, rewriting is that one's), and never measure with skill-creator's `run_eval`/`run_loop`, which produces systematic false zeros.

best for

Any marketplace maintainer deciding whether a skill's description actually triggers and whether it is fit to ship, who wants honest numbers instead of the stub-harness ~0 false-negatives.
