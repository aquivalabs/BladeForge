review:review v2.11.1

Routes an agent reaching for the review gate to the /review COMMAND, because reaching for it as a skill silently runs a different reviewer that cannot attest.

see it

fires when

Use when an ALREADY-CONFIGURED pre-push gate is about to be run against a branch, or its result attested — "run the review", "review before I push", "run the gate", "re-review after the fixes", "review this branch and attest it", "the gate is green, write the attestation", or any attempt to reach that gate through the Skill tool. The gate is a slash COMMAND, not a skill, and reaching for it as a skill silently runs a different reviewer that scores against no threshold and can attest nothing. Do NOT use for an ad-hoc read of a diff where no gate or attestation is wanted (that is the built-in `/code-review`), nor to create a gate that does not exist yet (`review:setup`).

best for

Any repo that runs the pre-push review gate and is worked by agents that may reach for it through the Skill tool.
